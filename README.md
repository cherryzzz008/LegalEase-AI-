# LegalEase AI

AI-powered legal document generator.

## Features

- Generate legal document drafts using Gemini AI
- Preview and edit generated documents
- Export documents as TXT, DOCX, and PDF
- FastAPI backend
- Streamlit frontend

## Technologies Used

- Python
- FastAPI
- Streamlit
- Google Gemini AI
- python-docx
- FPDF

## Project Structure

- `backend/` – FastAPI backend and AI generation
- `frontend/` – Streamlit user interface
- `requirements.txt` – Python dependencies
- `Documents/` – Project documents

## Important Note

This project generates AI-assisted legal document drafts.
The generated documents should be reviewed by a qualified legal professional before use.
